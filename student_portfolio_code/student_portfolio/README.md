# Student Developer Portfolio

A responsive personal portfolio made with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content
- `style.css` — design and responsive styles
- `script.js` — mobile navigation, active section, project details, and footer year
- `assets/` — place your real photos and project screenshots here

## Run locally
1. Extract the ZIP file.
2. Open the `student_portfolio` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Replace all placeholders before publishing.

## Personalize before submitting
1. Replace `Your Name` and `YOURPORTFOLIO` in `index.html`.
2. Change `YN` in the hero avatar to your initials, or replace the avatar with your own photo.
3. Replace `your.email@example.com` with your real email in both the mailto link and displayed email.
4. Replace the GitHub and LinkedIn links with your actual profile links, or remove them if you do not have profiles.
5. Update each project’s status, contribution, and technologies. Do not claim features you have not built.
6. Replace the CSS-made illustrative project graphics with screenshots of your actual projects if available.
7. Update your current year level and academic year.
8. Test all links and check the layout on mobile and desktop.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new public repository, for example `student-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository root.
3. Open the repository's **Settings**.
4. Select **Pages** from the sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder, then save.
7. Wait for GitHub Pages to publish the site and copy the public HTTPS URL shown on the Pages settings screen.
8. Open the public URL in a private/incognito window to verify it works.

The project graphics in this starter version are illustrative CSS artwork, not screenshots of completed apps. Replace them with authentic screenshots where possible.
